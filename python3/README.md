# mbse-sysarch (Python)

The Python implementation of [mbse-sysarch](https://github.com/pitaman71/mbse-sysarch): `mbse.Architecture.Systems`,
beside `mbse.Schemas` in the shared `mbse` namespace package. See the repository's README.

| Module | What it holds |
|---|---|
| `mbse.Architecture.Systems.Framework.Structure` | `define(store)`, `Check`, `hard_containers`, `is_soft`, `organizer` |
| `mbse.Architecture.Systems.Framework.Interactions` | `define(store)`, `Check`, `path`, `module_of`, `message_schema`, `distribution`, `ends` |
| `mbse.Architecture.Systems.Examples.Pipeline` | `build(store)`, and the helpers `module` and `connect`; runnable as a self-checking script |
| `mbse.Architecture.Systems.Conformance` | the corpus's cases and its writer |
